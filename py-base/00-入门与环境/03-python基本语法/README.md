本章 `` `[Rn]` `` 索引**仅在本章有效**，完整链接见第 7 节；标注「实测」的是本机运行结果，不是官方依据。来源为 `python.org` 官方教程、PEP 与 CPython 官方仓库。

## 1. 概念

### 1.1 缩进是语法，注释以 `#` 开始

- Python 用**缩进**分组语句，同一基本块内每行缩进量必须一致；官方教程的 Fibonacci 示例即以缩进标记 `while` 的循环体。`[R1]`
- 注释以 `#` 开始、延伸到物理行结束；字符串字面量里的 `#` 只是普通字符。`[R1]`
- PEP 8 规定每层用 4 个空格、不用 tab；Python **禁止混用 tab 与空格**作缩进。`[R3]`

> 这是本章与 C / Java / TypeScript 最大的差别：缩进不是排版偏好，写错程序直接无法运行。

### 1.2 字面量与内置类型

| 类型 | 写法 | 官方要点 | 依据 |
| --- | --- | --- | --- |
| `int` | `2`、`20` | 整数 | `[R1]` |
| `float` | `5.0`、`1.6` | `/` **永远**返回 float；混合类型运算把 int 转为 float | `[R1]` |
| `str` | `'...'`、`"..."` | 单双引号等价，`\n` 等转义在两者中含义相同 | `[R1]` |
| `bool` | `True` / `False` | 条件判断的结果类型；不与 `==` 比较（见 5 节） | `[R3]` |
| `NoneType` | `None` | 表示无值；比较时用 `is None` | `[R3]` |

运算符要点 `[R1]`：`+ - * /` 四则、`()` 分组、`//` 向下整除、`%` 取余、`**` 幂；注意 `**` 优先级高于一元 `-`，`-3**2` 结果是 `-9`，要写 `(-3)**2` 才得 `9`。标准比较运算符为 `< > == <= >= !=`。`[R1]`

字符串细节 `[R1]`：

- 转义用 `\`；原始字符串 `r'...'` 不解释反斜杠，但**不能以奇数个反斜杠结尾**；三引号 `"""..."""` 可跨行。
- 相邻**字面量**自动拼接（`'Py' 'thon'` → `'Python'`），但变量与字面量不会自动拼接，必须用 `+`。
- 索引从 0 开始，负索引从 `-1` 开始；没有单独的「字符类型」，一个字符就是长度为 1 的字符串。
- 切片 `s[i:j]` 含起点、不含终点，省略端点有默认值；`s[:i] + s[i:]` 恒等于 `s`。
- 字符串**不可变**，给索引位置赋值会抛 `TypeError`，需要新字符串请重新构造。
- `len(s)` 返回长度。

f-string（`f"...{expr}..."`）是带内嵌表达式的字符串字面量，官方教程的控制流示例大量使用。`[R2]` 本章示例只用 `print()` 的多参数形式，f-string 在后续章节自然出现。

### 1.3 变量与赋值

- `=` 给变量赋值，**无需声明类型**；赋值后交互模式不回显结果。使用未赋值（未定义）的名字会抛 `NameError`。`[R1]`
- 多重赋值 `a, b = 0, 1`：右侧表达式**先全部求值**，再依次赋值，且按从左到右求值。`[R1]`
- 交互模式下 `_` 保存上一次打印的表达式结果；官方明确要求把它当**只读**，不要显式赋值，否则会创建同名局部变量遮蔽它。`[R1]`

> 变量与对象的关系（名字绑定、赋值不复制数据）由第 04 章用官方原文展开；本章只需记住「名字必须先用 `=` 绑定过」。

### 1.4 控制流

| 语句 | 官方要点 | 依据 |
| --- | --- | --- |
| `if` / `elif` / `else` | `elif` 可零到多个，`else` 可选；`elif` 是 `else if` 的缩写，用来避免过深缩进，可替代其他语言的 `switch` | `[R2]` |
| `for` | 迭代**任意序列**中的项，按出现顺序；不是 C 式的三段循环 | `[R2]` |
| `while` | 条件为真时重复执行 | `[R1]` `[R2]` |
| `range()` | 生成算术序列，终点**不包含**；`range(10)` 给长度 10 序列的合法索引；返回的是 iterable、不真的造出 list，因而省空间 | `[R2]` |
| `break` / `continue` | `break` 跳出**最内层** `for` / `while`；`continue` 进入下一轮 | `[R2]` |
| 循环 `else` | 循环未触发 `break` 才执行；官方说它更像 `try` 的 `else` 而不是 `if` 的 `else` | `[R2]` |
| `pass` | 什么都不做，用于语法上需要语句但无需动作之处 | `[R2]` |
| `match` | 只执行第一个匹配的 `case`；`_` 是永不失败的通配符；无匹配则所有分支都不执行 | `[R2]` |

两条官方明确的实践 `[R2]`：

- **遍历集合时修改同一个集合很容易出错**，应遍历副本或新建集合。
- 需要同时拿到索引和值时用 `enumerate()`，比 `range(len(a))` 方便。

复合条件（`and` / `or` / `not`、链式比较、`in` 成员测试）依赖容器语义，放在第 04 章展开；`match` 的类模式、映射模式依赖对象模型，第 08–09 章之后才有意义。`[R1]` `[R2]`

### 1.5 基本 I/O

- `print()` 可接收多个参数、字符串不带引号输出、参数间自动插入空格；关键字参数 `end` 可改变行尾。`[R1]`
- `input()` 返回**字符串**；要做数值运算必须显式转换，官方示例写作 `int(input(...))`。`[R2]`
- 在 REPL 里直接写表达式会回显值，写程序时用 `print()` 输出。`[R1]`

### 1.6 本章的边界

函数（第 05 章）、类（第 08 章）、异常处理（第 16 章）、`import`（第 21 章）都不在本章出现。示例遇到错误时直接让程序终止，这是刻意安排。

## 2. 注意事项

1. **缩进混用 tab 与空格会直接报错**，统一 4 空格。`[R3]`
2. **`/` 返回 float**，别把它当整除；要整数用 `//`。`[R1]`
3. **未定义变量是 `NameError`**，Python 不会给默认值。`[R1]`
4. **原始字符串不能以奇数个 `\` 结尾**。`[R1]`
5. **字符串不可变**，别尝试 `s[0] = 'J'`。`[R1]`
6. **索引越界抛 `IndexError`，切片越界被优雅截断**——两者行为不同。`[R1]`
7. **循环 `else` 属于 `for` / `while`，不是 `if`**；被 `break` 终止时不执行。`[R2]`
8. **不要在遍历时增删正在遍历的集合**。`[R2]`
9. **交互模式的 `_` 只读**，不要给它赋值。`[R1]`
10. **`input()` 返回 `str`**，算术前先转换。`[R2]`

## 3. 边界考虑

| 边界 | 说明 | 依据 |
| --- | --- | --- |
| 数值精度 | `/` 得 float，混合运算把 int 提升为 float；精确十进制计算不在本章范围，属第 22 章标准库 | `[R1]` |
| 字符串索引单位 | 索引与 `len()` 按字符而非字节；实测 `len("查一下今天的 AI 新闻")` 为 `12` | `[R1]` + 实测 |
| 布尔与短路求值 | `and` / `or` 是短路运算符、返回最后求值参数；完整规则在第 04 章 | `[R1]` 章节边界 |
| `match` 能力边界 | 类模式、映射模式、guard 依赖对象模型，本章只要求读懂最简单的字面量 case | `[R2]` |
| 异常缺席 | `NameError` / `IndexError` 本章不捕获，第 16 章才系统处理 | 课程边界 |
| 源文件编码 | PEP 8：核心发行版代码一律 UTF-8、不加编码声明；标准库标识符必须 ASCII | `[R3]` |
| 风格不是铁律 | PEP 8 明确项目自身规范优先，且「一致性 > 机械遵守」 | `[R3]` |

## 4. 最佳实践

1. **先在 REPL / `python -c` 验证单个表达式**，再写进脚本（第 02 章的 REPL 就是为此准备的）。`[R1]`
2. 一次只增加一层缩进，全程 4 空格。`[R3]`
3. 多分支用 `elif` 而不是层层嵌套 `if`。`[R2]`
4. 要索引又要值时用 `enumerate()`，不写 `range(len(a))`。`[R2]`
5. 需要数字序列用 `range()`，不要先构造一个 list。`[R2]`
6. 遍历中要修改集合，先取副本或构建新集合。`[R2]`
7. 输出用 `print()` 多参数，不要手工拼字符串。`[R1]`

## 5. 最佳编码建议

- **4 空格、行宽 79 字符、运算符两侧各一个空格**，复合语句不写在同一行。`[R3]`
- **命名用 `lowercase_with_underscores`**，常量 `UPPER_CASE`；避免单字符 `l` / `O` / `I`。`[R3]`
- **与 `None` 比较用 `is` / `is not`，不用 `==`**；判空序列直接写 `if not seq`，别写 `if len(seq)`。`[R3]`
- **布尔值不与 `True` / `False` 用 `==` 比较**。`[R3]`
- **注释解释「为什么」**：`x = x + 1  # Increment x` 属于反例；行内注释与语句至少隔两个空格。`[R3]`
- **命名表达意图、显式优于隐式、失败要快且明确**（延续第 01 章约定）。

## 6. 编码示例

### 6.1 可运行脚本

`examples/basics_demo.py` 只使用本章语法，覆盖字面量、运算、字符串、条件、三种循环与 `print()`：

```python
"""第 03 章示例：基本语法综合演练。

只用本章语法：字面量、变量、运算符、字符串、条件、循环、print()。
函数 / 类 / import 分别在第 05 / 08 / 21 章展开。

运行（在本章目录下）：
    python examples/basics_demo.py
"""

# 1. 字面量与变量：模拟一次 Agent 回合的原始记录 [R1]
user_message = "查一下今天的 AI 新闻"
tool_call_count = 3
response_seconds = 1.5

print("用户输入:", user_message)
print("工具调用次数:", tool_call_count)
print("单次耗时:", response_seconds, "秒")

# 2. 算术与比较运算 [R1]
total_seconds = response_seconds * tool_call_count
print("估算总耗时:", total_seconds, "秒")
print("是否需要重试:", total_seconds > 10)

# 3. 字符串：切片、长度、不可变 [R1]
prefix = user_message[:3]
print("开头三个字符:", prefix)
print("消息长度:", len(user_message))

# 4. 条件分支 [R2]
if tool_call_count == 0:
    status = "未调用工具"
elif tool_call_count < 5:
    status = "正常"
else:
    status = "调用过多"
print("状态:", status)

# 5. for + continue：统计非空格字符 [R2]
non_space_chars = 0
for char in user_message:
    if char == " ":
        continue
    non_space_chars = non_space_chars + 1
print("非空格字符数:", non_space_chars)

# 6. range + break + 循环 else；break 触发时 else 不执行 [R2]
for attempt in range(1, 4):
    print("第", attempt, "次尝试")
    if attempt == 2:
        print("达到上限，提前结束")
        break
else:
    print("全部尝试完成")

# 7. while：倒计数 [R1]
remaining = tool_call_count
while remaining > 0:
    print("剩余待处理:", remaining)
    remaining = remaining - 1

# 8. 与 None 比较用 is，不用 == [R3]
missing_value = None
print("用 is None 判定:", missing_value is None)
```

运行（**先切到本章目录**，第 01 章的踩坑点）：

```powershell
cd 'E:\ai-agent-study\py-base\00-入门与环境\03-python基本语法'
python examples/basics_demo.py
```

本机实测输出：

```text
用户输入: 查一下今天的 AI 新闻
工具调用次数: 3
单次耗时: 1.5 秒
估算总耗时: 4.5 秒
是否需要重试: False
开头三个字符: 查一下
消息长度: 12
状态: 正常
非空格字符数: 10
第 1 次尝试
第 2 次尝试
达到上限，提前结束
剩余待处理: 3
剩余待处理: 2
剩余待处理: 1
用 is None 判定: True
```

> 注意输出里**没有**「全部尝试完成」：第 2 次尝试触发了 `break`，循环 `else` 因此不执行。`[R2]`
