## 0. 依据标注约定

本章 `` `[Rn]` `` 仅在本章有效，索引见第 7 节；「未直连核对」的链接按官方文档通行表述整理，需复核。

## 1. 概念

- 官方说明：函数执行会引入**新的局部符号表**；函数内所有赋值都存进局部符号表。名字引用依次查找：局部 → 外层函数的局部 → 全局 → 内建名字表。`[R1]` `[R2]`
- 由此得到常用的 **LEGB**（Local / Enclosing / Global / Built-in）记法；这是社区对上述官方描述的概括，不是语言关键字。`[R2]`
- **函数内给名字赋值 = 声明它是局部的**，除非用 `global`（模块级）或 `nonlocal`（外层函数级）显式声明。因此在赋值前先读取同名全局名字会抛 `UnboundLocalError`。`[R1]` `[R2]`
- 全局与外层变量**可以被引用，但不能直接赋值**——这是官方原文的结论，也是 `global` / `nonlocal` 存在的理由。`[R1]`
- 嵌套函数可以引用包含作用域的变量；变量在**调用时**按名字查找，而不是定义时复制值（闭包延迟绑定）。`[R1]` `[R2]`
- 类定义会引入新的命名空间，但**不构成闭包作用域**：方法体内不能直接引用类的局部变量，需走 `self` 或类名（第 08 章展开）。`[R2]`

## 2. 注意事项

1. **不要靠读全局变量传参**，显式传参更可读、可测。`[R1]` `[R3]`
2. **`global` 只影响赋值**，读取不需要声明。`[R1]`
3. **循环里创建闭包要小心延迟绑定**，需要固定值时用默认参数绑定。`[R2]`
4. **`from x import *` 污染命名空间**，PEP 8 要求避免。`[R3]`
5. **不要用与内建同名的变量**（`list`、`id`、`type`），会遮蔽内建名字表里的名字。`[R2]`
6. **模块级可变状态是并发隐患**，第 28 章会重新讨论。`[R2]`

## 3. 边界考虑

| 边界 | 说明 | 依据 |
| --- | --- | --- |
| 闭包不是快照 | 捕获的是名字，外层变量后续改动会被看到 | `[R2]` |
| `global` / `nonlocal` 的作用域 | 只改变名字绑定位置，不改变对象本身 | `[R1]` |
| 类作用域不参与闭包 | 列表推导式、嵌套函数在类体中的名字查找规则不同 | `[R2]` |
| 模块即全局作用域 | 每个模块有自己的全局符号表，跨模块共享状态要显式导入 | `[R2]` |
| 反射与动态名字 | `globals()` / `locals()` 可用于调试，但不应作为业务传参手段 | `[R2]` |

## 4. 最佳实践

1. **优先参数与返回值传递数据**，把 `global` 当作最后手段。`[R1]`
2. **把状态封装进对象**（第 08 章）而不是散落的模块级变量。`[R3]`
3. **闭包保持短小**，只捕获真正需要的名字。`[R2]`
4. **需要固定值时用默认参数当场绑定**，避免循环中的延迟绑定坑。`[R2]`
5. **配置走环境变量 / 配置中心**，密钥不硬编码（第 01 章安全底线）。

## 5. 最佳编码建议

- **常量用 `UPPER_CASE` 放模块级且不重新赋值**。`[R3]`
- **内部名字用单下划线前缀**，明确非公开。`[R3]`
- **注释解释「为什么用 global/nonlocal」**，这类非直觉取舍必须写理由。`[R3]`
- **显式优于隐式、不可变优先**（第 01 章）。
- **避免副作用传数据**：函数改变外部状态必须由名字和 docstring 明示（第 05 章）。

## 6. 编码示例

### 6.1 可运行脚本

`examples/scope_demo.py`：

```python
"""第 06 章示例：局部/全局作用域与闭包。"""

call_count = 0

def record_call():
    """用 global 显式声明后才赋值模块级名字 [R1]。"""
    global call_count
    call_count = call_count + 1
    local_value = call_count
    return local_value

def outer():
    """内层函数引用包含作用域的名字 [R1]。"""
    prefix = "call-"
    def inner(number):
        return prefix + str(number)
    return inner(2)

print("第 1 次:", record_call())
print("第 2 次:", record_call())
print("模块级计数:", call_count)
print("闭包:", outer())
```

运行：

```powershell
cd 'E:\ai-agent-study\py-base\01-函数与作用域\06-作用域'
python examples/scope_demo.py
```

关键输出：计数依次为 `1`、`2`、`模块级计数: 2`；闭包输出 `call-2`，说明内层函数能读到外层的 `prefix`。`[R1]`

### 6.2 反例（解释 `UnboundLocalError`）

```python
count = 0
def broken():
    print(count)
    count = count + 1
```

`count =` 让 `count` 在整个函数内成为局部名字，于是第一行的读取发生在赋值之前，抛 `UnboundLocalError`。`[R2]`
