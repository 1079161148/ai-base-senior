## 0. 依据标注约定

本章 `` `[Rn]` `` 仅在本章有效，索引见第 7 节；「未直连核对」的链接按官方文档通行表述整理。

## 1. 概念

- 调用 `C(args)` 时，先由 `__new__` **创建**实例，再由 `__init__` **初始化**它；`__new__` 是静态方法（实际接收类作为第一参数），`__init__` 是实例方法。`[R1]`
- `__new__` 必须返回一个实例（通常是 `super().__new__(cls)` 的结果）；**若返回的不是 `cls` 的实例，`__init__` 不会被调用**。`[R1]`
- `__init__` 必须返回 `None`，返回其他值会抛 `TypeError`。`[R1]`
- `object.__new__` 是最基础的实现；重写时要正确传 `cls`，否则会破坏实例化。`[R1]`
- 重写 `__new__` 的典型理由是**子类化不可变类型**（`str` / `tuple` / `int`）——它们的值在 `__new__` 阶段就已确定，`__init__` 改不了。`[R1]`
- 更外层还有一步：元类的 `__call__` 负责触发 `__new__` / `__init__`，这是第 12 章的内容。`[R1]`
- 绝大多数业务类**只需要 `__init__`**；重写 `__new__` 属于进阶手段。`[R1]`

## 2. 注意事项

1. **`__new__` 少写、能不写就不写**，可读性差且易错。`[R1]`
2. **`__init__` 不要 `return` 值**，只写 `return` 都不必要。`[R1]`
3. **`super().__new__(cls)` 的参数要正确**，多继承下参数传递更需小心。`[R1]`
4. **不要在 `__init__` 里做重 I/O 或联网**，构造应可预测（第 08 章）。
5. **单例不要靠 `__new__` 硬凑**，优先模块级对象或依赖注入。`[R2]`

## 3. 边界考虑

| 边界 | 说明 | 依据 |
| --- | --- | --- |
| 返回非本类实例 | `__init__` 被跳过，容易写出难以理解的行为 | `[R1]` |
| 不可变类型 | 值在 `__new__` 时确定，必须在 `__new__` 里处理 | `[R1]` |
| 元类层级 | `C(args)` 之前还有 `type.__call__`，见第 12 章 | `[R1]` |
| 反序列化 | `pickle` / `copy` 可绕过常规创建路径，见第 22 章 | `[R1]` |
| 参数一致性 | `__new__` 与 `__init__` 收到同一批实参，签名要协调 | `[R1]` |

## 4. 最佳实践

1. **普通类只写 `__init__`**，把校验放在最前面。`[R1]`
2. **子类化 `str` / `tuple` 时才重写 `__new__`**，并写明原因注释。`[R1]`
3. **用 `super()` 而非硬编码基类名**。`[R2]`
4. **构造失败要快**：非法参数在 `__init__` 立即抛异常（第 16 章）。

## 5. 最佳编码建议

- **注释解释「为什么重写 `__new__`」**——这是典型的非直觉取舍。`[R2]`
- **命名表达意图、不做预留扩展**（第 01 章）。
- **不在构造函数里吞异常**（第 16 章）。
- **配置外置、密钥不硬编码**（第 01 章）。

## 6. 编码示例

`examples/creation_demo.py`：

```python
"""第 10 章示例：__new__ 与 __init__ 的调用顺序。"""

class Traced:
    """打印创建过程的顺序。"""
    def __new__(cls, name):
        print("1 __new__:", name)
        instance = super().__new__(cls)
        return instance

    def __init__(self, name):
        print("2 __init__:", name)
        self.name = name

obj = Traced("search")
print("3 结果:", isinstance(obj, Traced), obj.name)
```

运行：

```powershell
cd 'E:\ai-agent-study\py-base\02-面向对象基础\10-对象的创建过程'
python examples/creation_demo.py
```

输出严格按 `1 __new__` → `2 __init__` → `3 结果` 顺序，印证两步分工。`[R1]`
