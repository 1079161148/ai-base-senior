## 1. 概念

- `class Name:` 定义类；类体在定义时执行并产生新的命名空间；实例化通过 `ClassName(args)` 调用。`[R1]` `[R2]`
- `__init__` 是实例创建后被调用的初始化方法；`self` 是实例本身，按约定作为方法的第一个参数（PEP 8 要求始终用 `self`）。`[R1]` `[R3]`
- 方法就是定义在类体里的函数，通过 `obj.method()` 调用时实例作为第一个参数自动传入。`[R1]` `[R2]`
- **属性查找先实例、再类**；类属性被所有实例共享，实例属性属于单个实例。给 `self.x` 赋值只影响当前实例。`[R1]` `[R2]`
- 可变类属性会被所有实例共享，和函数可变默认值是同一类陷阱（第 05 章）。`[R1]`
- 继承写法 `class Derived(Base):`，方法查找沿 MRO；`super()` 用于调用基类实现。`[R1]`
- Python 没有真正的 private：单下划线是「内部使用」约定，双下划线触发名称改写（name mangling）。`[R3]`

## 2. 注意事项

1. **不要用可变对象作类属性**存放实例级状态。`[R1]`
2. **方法第一个参数必须写 `self`**，调用时不要手动传。`[R3]`
3. **类属性与实例属性同名会遮蔽**，排查时先看 `obj.__dict__` 与类名。`[R2]`
4. **不要在 `__init__` 里做重 I/O**，构造应轻量；资源用上下文管理器（第 18 章）。`[R1]`
5. **不要发明 `__xxx__` 名字**，双前后下划线保留给语言机制（第 14 章）。`[R3]`
6. **公共 API 优先暴露简单属性**，需要时再用 property 包装，别一上来写一堆 getter/setter。`[R3]`

## 3. 边界考虑

| 边界 | 说明 | 依据 |
| --- | --- | --- |
| 类作用域不参与闭包 | 方法体里不能直接引用类体的局部名字，要走 `self` 或类名 | `[R2]` |
| 名称改写不是访问控制 | `_Class__x` 仍可访问，双下划线只用于避免子类属性冲突 | `[R3]` |
| 继承深度 | 多继承 MRO 复杂，优先组合而非深层继承 | `[R1]` |
| 实例化过程 | `__new__` 与元类在第 10 / 12 章展开 | `[R2]` |
| 数据共享 | 类属性、默认参数、闭包都可能共享可变对象 | `[R1]` |

## 4. 最佳实践

1. **用组合代替深层继承**，让依赖显式可见。`[R1]`
2. **`__init__` 只做赋值与校验**，把副作用留给显式方法。`[R1]`
3. **需要「常量」用不可变类属性或模块常量**。`[R3]`
4. **优先 `dataclasses` 处理纯数据类**（第 13 章装饰器会用到）。`[R2]`
5. **为公共类写 docstring**，说明职责与关键不变量。`[R3]`

## 5. 最佳编码建议

- **类名用 `CapWords`，方法与实例变量用 `lowercase_with_underscores`**。`[R3]`
- **实例方法首参数固定 `self`，类方法固定 `cls`**。`[R3]`
- **注释解释「为什么这样设计继承 / 共享状态」**。`[R3]`
- **显式优于隐式、不可变优先、失败要快**（第 01 章）。
- **不硬编码凭据，外部输入在服务端校验**（第 01 章安全底线）。

## 6. 编码示例

### 6.1 可运行脚本

`examples/class_demo.py`：

```python
"""第 08 章示例：类、实例与 __init__。"""

class ToolCall:
    """一次工具调用的记录。"""

    kind = "tool"

    def __init__(self, name, arguments):
        self.name = name
        self.arguments = arguments

    def describe(self):
        """返回可读描述。"""
        return self.kind + ":" + self.name + "=" + str(self.arguments)

call = ToolCall("search", {"query": "AI news"})
print("实例属性:", call.name, call.arguments)
print("类属性:", call.kind)
print("方法:", call.describe())
```

运行：

```powershell
cd 'E:\ai-agent-study\py-base\02-面向对象基础\08-类和对象'
python examples/class_demo.py
```

关键输出：`实例属性: search {'query': 'AI news'}`、`类属性: tool`、`方法: tool:search={'query': 'AI news'}`。`kind` 来自类属性，`name` / `arguments` 来自实例。`[R1]` `[R2]`

### 6.2 共享可变类属性的反例

```python
class Bad:
    items = []
```

所有 `Bad()` 实例共享同一个 `items`，与第 05 章 `L=[]` 是同一类问题。`[R1]`
