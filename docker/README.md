## 环境相关注意事项

| 事实 | 说明 |
| --- | --- |
| Docker 29 端口冲突文案 | `failed to set up container networking`（第 17 章记录） |
| BuildKit 进度走 stderr | 统计 `CACHED` 必须合并 stdout+stderr（第 19 章） |
| 镜像 ID 每次构建都变 | 改用 `RootFS.Layers` 比对（第 19 章） |
| 镜像 `.Size` 是压缩后大小 | 用不可压缩数据测体积（第 20 章） |
| manifest 需 `Accept` 头 | 读取 OCI manifest 必须带（第 24 章） |
| scout 需登录 | 未登录 `quickview` 直接提示（第 32 章） |
| 多平台 `--load` | containerd 存储下可成功，经典 overlay2 会失败（第 33 章） |
| `--gpus all` 不等于能用 GPU | 还需驱动与 CUDA 镜像（第 34 章） |
| PID 1 忽略 SIGTERM | 无 `--init` 时 `docker stop` 得 137（第 36 章） |

5. 按 36 章走一次发布与回滚演练。

四步走完，Docker 从"会一点"变成"能落地"。
