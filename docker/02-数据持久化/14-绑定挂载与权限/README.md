# 14 绑定挂载与权限

## 一句话结论

绑定挂载把宿主目录**直接映射**进容器，改文件立即生效，适合配置和代码。两条铁律：**绑定挂载会覆盖镜像内原内容**（不像空命名卷会复制）；**只读加 `:ro`**，SELinux 系统再加 `:z`。

## 最小可运行案例

```bash
docker run -d --name web \
  -v "$(pwd)/html:/usr/share/nginx/html:ro" \
  -p 8080:80 nginx:alpine
```

## 怎么跑

```powershell
cd "02-数据持久化\14-绑定挂载与权限\examples"

```

## 挂载选项后缀

| 后缀 | 含义 | 场景 |
| --- | --- | --- |
| （无） | 读写 | 开发时代码热更新 |
| `:ro` | 只读 | 配置文件、静态资源 |
| `:z` | SELinux 共享标签 | Rocky/RHEL 报 Permission denied |
| `:Z` | SELinux 私有标签 | 仅该容器可用 |
| `:ro,z` | 只读 + SELinux | 生产静态资源 |

## 绑定挂载 vs 命名卷（关键差异）

| 行为 | 绑定挂载 | 命名卷 |
| --- | --- | --- |
| 宿主路径可见 | 是 | 在 `/var/lib/docker/volumes` 下 |
| 首次挂到非空镜像目录 | **覆盖**，原内容不可见 | **复制**镜像内容进空卷 |
| 宿主直接编辑 | 支持 | 不推荐 |
| 由 Docker 管理 | 否 | 是 |
| 跨平台性能 | Windows/macOS 较慢 | 好 |

本机实测：空目录挂到 nginx 的 html 目录后，原 `index.html` 消失（`ls` 为空）；而空命名卷挂同一目录会得到 `50x.html index.html`。

## 最容易踩的坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 挂载后页面 403 | 空目录覆盖了原文件 | 放好文件或用卷 |
| 改了配置不生效 | 编辑器替换 inode | 挂目录而非单文件 |
| SELinux `Permission denied` | 缺安全标签 | 加 `:z` |
| 相对路径 `./data` | 被当成卷名 | 用绝对路径 |
| 容器内写只读目录 | `:ro` 生效 | 去掉 ro 或改挂载点 |
| Windows 路径反斜杠 | 解析失败 | 用正斜杠 `/` |
| 单文件挂载后更新丢失 | inode 被替换 | 重启容器或挂目录 |
