# agent-lab 架构说明

agent-lab 是一个从零实现的 AI Agent 学习项目，目标是跑通一个完整闭环：
**对话 → 工具调用 → 知识检索 → 任务规划 → 评测 → 可观测 → 安全 → 部署**。

## 分层结构

- `api/v1`：HTTP 层，只做参数解析与串联，不写业务逻辑
- `services`：业务层，可被脚本和工具直接复用
- `core`：基础设施（配置、数据库、SSE 编码、错误、鉴权）
- `models`：Pydantic 模型，负责输入校验与输出序列化

## 记忆的三层

1. **短期记忆**：当前会话的消息列表，直接进上下文
2. **长期记忆**：跨会话保留的事实，按向量相似度召回
3. **工作记忆**：会话摘要，压缩历史，控制 token 预算

## 上下文预算

每次请求前估算 token 占用，超过阈值时按顺序压缩：
先删最早的消息，再压缩为摘要，最后才丢弃长期记忆。
预算条在对话页面实时显示，让用户看得见"模型还记得多少"。

## 混合检索

检索使用向量检索加 BM25 关键词检索，再用 RRF（Reciprocal Rank Fusion）融合。
向量擅长语义相近，BM25 擅长精确命中专有名词，两者互补。
RRF 的价值在于不需要调权重：只用排名做融合，换数据集也不用重新调参。
