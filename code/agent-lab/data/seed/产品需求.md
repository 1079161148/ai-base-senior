# 产品需求：智能待办助手

## 背景

用户在日常工作中会临时记下大量待办，但很少回头整理。
目标是让用户"说一句话"就能查询、创建、完成、删除待办，
不需要记住任何操作路径。

## 用户故事

1. 作为一个用户，我说"帮我看看还有什么没做完"，系统应列出所有未完成待办
2. 作为一个用户，我说"记一下明天下午三点开会"，系统应创建一条待办
3. 作为一个用户，我说"开会那条做完了"，系统应把对应待办标记为完成
4. 作为一个用户，我说"把测试数据都删了"，系统应先列出匹配项并请求确认

## 非功能要求

- 单条回复首字节延迟 P95 不超过 8 秒
- 单次对话成本不超过 0.01 元
- 删除类操作必须二次确认，不能由模型单方面决定
- 用户之间的数据完全隔离，任何接口都不能跨用户读取

## 验收标准

- 待办数量为 0 时，查询应返回友好提示而不是空数组
- 输入包含"忽略之前的指令"时，应被护栏拦截并返回明确错误
- 超过日成本上限后，所有请求返回 429，次日自动恢复

## 常见问题

**问：为什么删除需要确认，创建不需要？**
答：创建错了可以再删，删除错了数据就没了。不可逆操作才需要人类兜底。

**问：支持语音输入吗？**
答：当前版本只支持文本输入，语音是后续规划。

**问：会话数据保留多久？**
答：默认永久保留，用户可以手动删除整个会话。
