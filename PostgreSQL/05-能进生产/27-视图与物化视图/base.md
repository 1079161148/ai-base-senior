# 27 视图与物化视图 · 完整版

## 0. 怎么用

跑 11/11，再看第 4 节理解刷新策略。

## 1. 概念

视图不存数据，物化视图存结果。取舍是实时性换查询性能。

## 2. 机制

```text
VIEW → 查询重写 → 每次读基表
MATERIALIZED VIEW → 存堆表 → REFRESH 时重算
```

## 3. API 逐个拆解

| API | 作用 | 注意 |
| --- | --- | --- |
| `CREATE VIEW` | 建视图 | 可更新需满足条件 |
| `WITH CHECK OPTION` | 写入约束 | 防绕过视图条件 |
| `CREATE MATERIALIZED VIEW` | 建物化视图 | 不自动更新 |
| `REFRESH ... CONCURRENTLY` | 并发刷新 | 需唯一索引 |
| `pg_matviews` | 元数据 | 查定义 |

## 4. 边界条件

- 含聚合、DISTINCT、JOIN 的视图通常不可直接更新。
- `REFRESH CONCURRENTLY` 需唯一索引且不能在同一事务多次刷新。
- 视图依赖基表列，删列会失败。

## 5. 注意事项对照表

| 错误写法 / 操作 | 现象 | 正确写法 | 依据 |
| --- | --- | --- | --- |
| 物化视图当实时 | 数据旧 | 定期 REFRESH | 实测 |
| CONCURRENTLY 无唯一索引 | 报错 | 先建 | 实测 |
| 复杂视图当可更新 | 报错 | INSTEAD OF 触发器 | 实测 |
| 视图层级过深 | 慢 | 控制层级 | 实测 |
| 不查 pg_views | 结构不清 | 查元数据 | 实测 |
| REFRESH 高峰执行 | 锁读 | CONCURRENTLY | 实测 |
| 物化视图无索引 | 查询慢 | 建索引 | 实测 |
| WITH CHECK OPTION 漏写 | 数据绕过条件 | 补上 | 实测 |
| VIEW 名与表同名 | 冲突 | 命名区分 | 实测 |
| 不测 REFRESH 前后 | 不知是否生效 | 补计数 | 实测 |
| 依赖列被删 | 视图失效 | 先改视图 | 实测 |
| 把视图当权限边界 | 不完整 | 配合 GRANT | 第 30 章 |
| 物化视图无刷新策略 | 永远旧 | 定时任务 | 实测 |
| 不记录刷新时间 | 不知新鲜度 | 存日志表 | 实测 |
| 大物化视图全量刷新 | 开销大 | 分区+增量 | 第 26 章 |
| 跳过验收 | 刷新逻辑未验 | 11/11 再走 | 实测 |
| 以为 REFRESH 会删索引 | 索引保留 | 理解语义 | 实测 |
| 不使用 schema 隔离 | 命名冲突 | chNN | 实测 |

## 6. 最佳实践

报表用物化视图 + 定时并发刷新；业务查询用普通视图简化接口。
