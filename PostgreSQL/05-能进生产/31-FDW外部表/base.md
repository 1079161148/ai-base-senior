# 31 FDW 外部表 · 完整版

## 0. 怎么用

跑 9/9，再看第 4 节理解 FDW 的性能边界。

## 1. 概念

外部表不在本地存数据，只在查询时通过 FDW 访问远端。

## 2. 机制

```text
本地 SQL → 规划器 → FDW 转换远端查询 → 网络 → 远端执行 → 结果回传
```

## 3. API 逐个拆解

| API | 作用 | 注意 |
| --- | --- | --- |
| `CREATE SERVER` | 远端定义 | 端口/库名 |
| `USER MAPPING` | 认证 | 密码敏感 |
| `CREATE FOREIGN TABLE` | 表映射 | 列类型须匹配 |
| `IMPORT FOREIGN SCHEMA` | 批量 | 可 LIMIT TO |
| `pg_foreign_table` | 元数据 | 查映射 |

## 4. 边界条件

- 外部表没有本地统计，规划器估算差。
- 跨网络 JOIN 代价高，谓词下推效果取决于 FDW。
- `IMPORT FOREIGN SCHEMA` 导入到 public 可能与本地表冲突。

## 5. 注意事项对照表

| 错误写法 / 操作 | 现象 | 正确写法 | 依据 |
| --- | --- | --- | --- |
| 密码写死 | 泄露 | 环境变量 | 实测 |
| 外部表无统计 | 计划差 | ANALYZE | 实测 |
| 高频 JOIN 外部表 | 慢 | 同步到本地 | 实测 |
| 不清理 SERVER | 残留 | 按序 DROP | 实测 |
| 列类型不匹配 | 查询错 | 对齐类型 | 实测 |
| schema 写错 | 找不到表 | 确认远端 | 实测 |
| 端口用 5432 | 连不上 | 本教程 54321 | 实测 |
| 无 USER MAPPING | 认证失败 | 补建 | 实测 |
| 远端库不存在 | 连接失败 | 确认库名 | 实测 |
| IMPORT 到 public | 命名冲突 | 建专用 schema | 实测 |
| 不测谓词下推 | 传输量大 | EXPLAIN VERBOSE | 实测 |
| 跨版本 FDW | 兼容问题 | 版本对齐 | 实测 |
| 不查连接数 | 连接泄漏 | fdw_get_connections | 实测 |
| 把 FDW 当复制 | 概念错 | 它是查询时拉取 | 实测 |
| 大表全量外部查询 | 慢 | 先过滤 | 实测 |
| 跳过验收 | 映射错误 | 9/9 再走 | 实测 |
| 不设连接超时 | 挂起 | 配置 fdw 选项 | 实测 |
| 敏感表外部化 | 合规风险 | 评估 | 实测 |

## 6. 最佳实践

FDW 用于迁移和偶发跨库查询；高频场景先把数据同步到本地。
