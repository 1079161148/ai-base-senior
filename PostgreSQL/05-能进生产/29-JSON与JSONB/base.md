# 29 JSON 与 JSONB · 完整版

## 0. 怎么用

跑 12/12，再看第 4 节理解 JSONB 的取舍。

## 1. 概念

JSONB 是二进制 JSON，支持索引、去重和高效包含查询；JSON 保留原文和键顺序。

## 2. 机制

```text
JSON 文本 → 解析 → 二进制树 → GIN 倒排 → @> 查询走索引
```

## 3. API 逐个拆解

| API | 作用 | 注意 |
| --- | --- | --- |
| `->` | JSON 值 | 保留引号 |
| `->>` | 文本 | 去引号 |
| `#>` | 路径 | 数组下标从 0 |
| `@>` | 包含 | 可嵌套 |
| `jsonb_set` | 更新 | 路径须存在 |
| `jsonb_agg` | 聚合 | 顺序可 ORDER BY |

## 4. 边界条件

- JSONB 不保留键顺序和重复键。
- `jsonb_set` 默认不创建缺失路径，需 `create_missing=true`。
- GIN 默认支持 `@>`、`?`、`?|`、`?&`。

## 5. 注意事项对照表

| 错误写法 / 操作 | 现象 | 正确写法 | 依据 |
| --- | --- | --- | --- |
| JSON 建 GIN | 不支持 | 用 JSONB | 实测 |
| `->` 当文本 | 带引号 | `->>` | 实测 |
| LIKE 查 JSON | 慢/错 | `@>` | 实测 |
| 不建 GIN | 全表扫 | 建索引 | 通用实践 |
| jsonb_set 路径不存在 | 不生效 | create_missing | 实测 |
| 大 JSONB 频繁更新 | 膨胀 | 拆列 | 第 25 章 |
| 数字当字符串比较 | 类型错 | `->>` 转数值 | 实测 |
| 数组下标从 1 开始 | 取错 | 从 0 | 实测 |
| 路径写法用点号 | 报错 | 数组形式 | 实测 |
| 不测 NULL JSONB | 语义混 | IS NULL | 实测 |
| JSONB 当 TEXT | 丢语义 | 用类型 | 实测 |
| 无 GIN 却 @> | 慢 | 建索引 | 实测 |
| 聚合无 ORDER BY | 顺序不稳 | 加排序 | 第 10 章 |
| 不查类型元数据 | 靠猜 | information_schema | 实测 |
| 用 JSON 存 schema 固定数据 | 失去约束 | 用列 | 实测 |
| 跳过验收 | 操作符混淆 | 12/12 再走 | 实测 |
| 把 JSONB 当文档库全部替代 | 复杂 JOIN 仍弱 | 混合使用 | 通用实践 |
| 不记录 JSON 结构 | 维护难 | 文档化 | 实测 |

## 6. 最佳实践

半结构化字段用 JSONB + GIN；稳定字段仍拆成普通列以便约束和索引。
