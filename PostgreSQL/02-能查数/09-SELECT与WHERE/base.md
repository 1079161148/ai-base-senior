# 09 SELECT 与 WHERE · 完整版

## 0. 怎么用

跑 13/13，再读第 4 节理解三值逻辑。

## 1. 概念

SQL 查询是声明式的：你描述结果集的特征，优化器决定怎么取。

## 2. 机制

```text
FROM → WHERE → SELECT → ORDER BY → LIMIT
```

WHERE 在 SELECT 之前执行，所以别名不能在 WHERE 里用。

## 3. API 逐个拆解

| API | 作用 | 注意 |
| --- | --- | --- |
| `AS` | 别名 | 中文别名用双引号或直接写 |
| `IN` | 多值匹配 | 列表含 NULL 会出错 |
| `BETWEEN` | 闭区间 | 日期要用 `>=` + `<` 更稳 |
| `LIKE` | 模式匹配 | `%` 任意长度，`_` 一个字符 |
| `IS NULL` | 空判断 | 不能用 `=` |

## 4. 边界条件

- SQL 是三值逻辑：TRUE / FALSE / UNKNOWN。
- `NOT IN (..., NULL)` 永远返回空集。
- `LIKE` 模式里的 `%` 在前无法用普通 B-tree 索引。

## 5. 注意事项对照表

| 错误写法 / 操作 | 现象 | 正确写法 | 依据 |
| --- | --- | --- | --- |
| `= NULL` | 零行 | IS NULL | 实测 |
| NOT IN 含 NULL | 零行 | NOT EXISTS | 实测 |
| BETWEEN 当左闭右开 | 边界多算 | 显式 >= < | 实测 |
| LIKE '%x' | 全表扫描 | 全文检索 | 通用实践 |
| WHERE 用 SELECT 别名 | 列不存在 | 重复表达式 | 实测 |
| SELECT * | 多余列 | 显式列名 | 通用实践 |
| 中文别名不加引号 | 一般可用 | 复杂名加双引号 | 实测 |
| 单引号包标识符 | 变成字符串 | 双引号 | 实测 |
| 日期字符串不标准 | 解析失败 | ISO 格式 | 通用实践 |
| 不测 NULL 分支 | 漏数据 | 补 IS NULL 用例 | 实测 |
| OR 忘加括号 | 逻辑错 | 显式括号 | 实测 |
| IN 列表过长 | SQL 巨大 | 用临时表 JOIN | 实测 |
| 大小写敏感判断 | 结果不符 | ILIKE 或 LOWER | 实测 |
| 不建索引就 LIKE | 慢 | 第 22 章 | 通用实践 |
| 用 `!=` 排除 NULL | 漏行 | IS DISTINCT FROM | 实测 |
| 把 NULL 当空串 | 语义混 | 区分 NULL 与 '' | 实测 |
| 不排序就分页 | 结果不稳 | 加 ORDER BY | 第 10 章 |
| 跳过验收 | 条件写错不自知 | 13/13 再走 | 实测 |

## 6. 最佳实践

所有「不等于」判断都想想 NULL 会不会被漏掉。
