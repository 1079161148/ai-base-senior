# 14 集合运算与窗口函数 · 完整版

## 0. 怎么用

跑 10/10，再看第 4 节理解窗口帧。

## 1. 概念

集合运算操作「结果集」；窗口函数操作「每一行周围的窗口」，不折叠行。

## 2. 机制

```text
OVER (PARTITION BY ... ORDER BY ... ROWS BETWEEN ...)
       分小组       组内顺序        帧范围
```

## 3. API 逐个拆解

| API | 作用 | 注意 |
| --- | --- | --- |
| `UNION` | 并集去重 | 列数类型须一致 |
| `EXCEPT` | 差集 | 左减右 |
| `row_number` | 唯一序号 | 并列也递增 |
| `rank` | 并列跳号 | 1,1,3 |
| `dense_rank` | 并列不跳 | 1,1,2 |
| `lag/lead` | 前后行 | 边界返回 NULL |
| `ROWS BETWEEN` | 物理行帧 | 与 RANGE 不同 |

## 4. 边界条件

- `RANGE BETWEEN` 按值范围，并列行会一起纳入。
- 窗口函数不能出现在 WHERE，要放在 SELECT 或外层。
- 窗口 ORDER BY 为 NULL 时位置由 `NULLS` 决定。

## 5. 注意事项对照表

| 错误写法 / 操作 | 现象 | 正确写法 | 依据 |
| --- | --- | --- | --- |
| UNION 列数不同 | 报错 | 对齐 | 实测 |
| UNION 不排序 | 顺序不定 | 外层 ORDER BY | 实测 |
| rank 当 row_number | 序号跳 | 按需求选 | 实测 |
| 窗口无 ORDER BY | 不确定 | 显式排序 | 实测 |
| WHERE 用窗口函数 | 报错 | 外层过滤 | 实测 |
| RANGE vs ROWS 混用 | 累计值不同 | 明确帧类型 | 实测 |
| PARTITION 键错 | 分组粒度错 | 检查业务键 | 实测 |
| lag 边界 NULL | 首行为空 | COALESCE | 实测 |
| 无索引窗口排序 | 慢 | 第 22 章 | 通用实践 |
| INTERSECT 列顺序不同 | 语义错 | 对齐 | 实测 |
| EXCEPT 方向写反 | 结果相反 | 左减右 | 实测 |
| 大表窗口排序 | 内存大 | 分页后算 | 实测 |
| 窗口别名在 WHERE | 不可用 | 子查询包一层 | 实测 |
| 用 GROUP BY 代替窗口 | 丢行 | 按需求选 | 实测 |
| 多窗口 ORDER 冲突 | 结果难读 | 统一排序 | 实测 |
| 不测并列数据 | rank 差异看不出 | 插入同值 | 实测 |
| 跳过验收 | 排名错不自知 | 10/10 再走 | 实测 |
| 把 UNION 当 JOIN | 语义混淆 | 一个是纵向一个是横向 | 实测 |

## 6. 最佳实践

「排名/累计/环比」用窗口函数；「每组一个值」用 GROUP BY。
