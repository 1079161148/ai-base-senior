# 39 IVFFlat索引 · 完整版

## 0. 怎么用

跑 7/7。IVFFlat 把向量分成 lists 个聚类，查询只探查 probes 个桶，用少量精度换取大幅提速。

## 1. 概念

本章聚焦「IVFFlat 索引」，是 M06 向量数据库体系中的一环，建立在前面关系型基础之上。

## 2. 机制

```text
→ USING ivfflat
→ lists
→ ivfflat.probes
```

## 3. API 逐个拆解

| API | 作用 | 注意 |
| --- | --- | --- |
| `USING ivfflat` | 倒排索引方法 | 见验收 |
| `lists` | 聚类数 | 见验收 |
| `ivfflat.probes` | 查询探查桶数 | 见验收 |
| `vector_l2_ops` | L2 算子类 | 见验收 |

## 4. 边界条件

- 向量维度必须与模型一致，算子要求维度相同。
- 近似索引以少量召回换取速度，需用评测校准。
- 教学用可复现向量验证机制，生产须换真实 embedding 模型。

## 5. 注意事项对照表

| 错误做法 | 现象 | 正确做法 | 依据 |
| --- | --- | --- | --- |
| 数据太少建索引 | 无收益 | 万行以上再建 | 实测 |
| lists 过大 | 每桶太小 | 约按 sqrt(n) 取值 | 实测 |
| probes 过小 | 召回下降 | 调大 probes | 实测 |
| 先建索引后灌数 | 聚类质量差 | 灌数后再建 | 实测 |

## 6. 最佳实践

先测正确性再测性能；每次调参都用固定评测集对比，避免凭感觉。
