# 38 距离算子与相似度排序 · 完整版

## 0. 怎么用

跑 8/8。<-> 是欧氏距离，<=> 是余弦距离，<#> 是负内积；按距离升序排列就是相似度降序。

## 1. 概念

本章聚焦「距离算子与相似度排序」，是 M06 向量数据库体系中的一环，建立在前面关系型基础之上。

## 2. 机制

```text
→ <->
→ <=>
→ <#>
```

## 3. API 逐个拆解

| API | 作用 | 注意 |
| --- | --- | --- |
| `<->` | L2 欧氏距离 | 见验收 |
| `<=>` | 余弦距离 | 见验收 |
| `<#>` | 负内积 | 见验收 |
| `ORDER BY ... LIMIT k` | 相似度排序 | 见验收 |

## 4. 边界条件

- 向量维度必须与模型一致，算子要求维度相同。
- 近似索引以少量召回换取速度，需用评测校准。
- 教学用可复现向量验证机制，生产须换真实 embedding 模型。

## 5. 注意事项对照表

| 错误做法 | 现象 | 正确做法 | 依据 |
| --- | --- | --- | --- |
| 归一化向量用 L2 | 排序近似但非最优 | 用余弦 <=> | 实测 |
| 忘记越小越近 | 排序反了 | 升序即最相似在前 | 实测 |
| 内积当距离 | 越大越近易混 | 用 <#> 需降序 | 实测 |

## 6. 最佳实践

先测正确性再测性能；每次调参都用固定评测集对比，避免凭感觉。
