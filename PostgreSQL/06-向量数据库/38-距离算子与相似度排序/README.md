# 38 距离算子与相似度排序

## 一句话结论

<-> 是欧氏距离，<=> 是余弦距离，<#> 是负内积；按距离升序排列就是相似度降序。

## 最小可运行案例

```sql
SELECT '[1,0]'::vector <-> '[0,1]'::vector AS l2,
       '[1,0]'::vector <=> '[0,1]'::vector AS cosine,
       '[1,0]'::vector <#> '[0,1]'::vector AS neg_ip;
```

## 核心 API 速查

| API | 作用 |
| --- | --- |
| `<->` | L2 欧氏距离 |
| `<=>` | 余弦距离 |
| `<#>` | 负内积 |
| `ORDER BY ... LIMIT k` | 相似度排序 |

## 最容易踩的坑

| 错误写法 | 现象 | 正确写法 |
| --- | --- | --- |
| 归一化向量用 L2 | 排序近似但非最优 | 用余弦 <=> |
| 忘记越小越近 | 排序反了 | 升序即最相似在前 |
| 内积当距离 | 越大越近易混 | 用 <#> 需降序 |
