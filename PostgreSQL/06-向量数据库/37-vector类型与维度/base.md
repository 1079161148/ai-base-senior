# 37 vector类型与维度 · 完整版

## 0. 怎么用

跑 7/7。vector(n) 把维度写进类型，插入不同维度会被直接拒绝；vector 不加 n 则维度自由但无法建索引。

## 1. 概念

本章聚焦「vector 类型与维度」，是 M06 向量数据库体系中的一环，建立在前面关系型基础之上。

## 2. 机制

```text
→ vector(n)
→ vector
→ vector_dims()
```

## 3. API 逐个拆解

| API | 作用 | 注意 |
| --- | --- | --- |
| `vector(n)` | 定长向量类型 | 见验收 |
| `vector` | 变长向量，不可建索引 | 见验收 |
| `vector_dims()` | 查询维度 | 见验收 |
| `::real[]` | 转数组 | 见验收 |

## 4. 边界条件

- 向量维度必须与模型一致，算子要求维度相同。
- 近似索引以少量召回换取速度，需用评测校准。
- 教学用可复现向量验证机制，生产须换真实 embedding 模型。

## 5. 注意事项对照表

| 错误做法 | 现象 | 正确做法 | 依据 |
| --- | --- | --- | --- |
| 改维度不重建列 | 旧数据不兼容 | 重建列并重新 embed | 实测 |
| 变长 vector 建索引 | 报错 | 用定长 vector(n) | 实测 |
| 维度与模型不符 | 结果无意义 | 维度绑定模型 | 实测 |

## 6. 最佳实践

先测正确性再测性能；每次调参都用固定评测集对比，避免凭感觉。
