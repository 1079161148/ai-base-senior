# 40 HNSW索引 · 完整版

## 0. 怎么用

跑 7/7。HNSW 用多层近邻图实现近似检索，召回通常优于 IVFFlat，构建更慢、内存更高。

## 1. 概念

本章聚焦「HNSW 索引」，是 M06 向量数据库体系中的一环，建立在前面关系型基础之上。

## 2. 机制

```text
→ USING hnsw
→ m
→ ef_construction
```

## 3. API 逐个拆解

| API | 作用 | 注意 |
| --- | --- | --- |
| `USING hnsw` | 图索引方法 | 见验收 |
| `m` | 每层连接数 | 见验收 |
| `ef_construction` | 构建时候选数 | 见验收 |
| `hnsw.ef_search` | 查询时候选数 | 见验收 |

## 4. 边界条件

- 向量维度必须与模型一致，算子要求维度相同。
- 近似索引以少量召回换取速度，需用评测校准。
- 教学用可复现向量验证机制，生产须换真实 embedding 模型。

## 5. 注意事项对照表

| 错误做法 | 现象 | 正确做法 | 依据 |
| --- | --- | --- | --- |
| ef_search 过小 | 召回低 | 调大 | 实测 |
| 高维 + 大 m | 内存爆 | 权衡 m | 实测 |
| 频繁更新 | 图维护贵 | 批量更新 | 实测 |
| 不评测就上线 | 效果未知 | 第 45 章 | 实测 |

## 6. 最佳实践

先测正确性再测性能；每次调参都用固定评测集对比，避免凭感觉。
