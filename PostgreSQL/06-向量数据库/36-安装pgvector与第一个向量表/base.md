## 1. 概念

pgvector 是 PostgreSQL 扩展，提供 `vector` 类型、距离算子和专用索引。扩展只需在每个数据库安装一次。

## 2. 机制

```text
CREATE EXTENSION vector → 注册类型/算子/索引方法 → vector(n) 列 → ORDER BY 距离 → Top-K
```

## 3. API 逐个拆解

| API | 作用 | 注意 |
| --- | --- | --- |
| `CREATE EXTENSION` | 安装 | 每库一次 |
| `vector(n)` | 定长向量 | n 为维度 |
| `<->` | L2 | 越小越近 |
| `vector_dims` | 维度 | 校验用 |
| `::vector` | 强转 | 参数常需要 |

## 4. 边界条件

- 扩展是数据库级对象，换库要重装。
- 向量字面量用方括号，逗号分隔。
- 未声明维度的 `vector` 可存任意维度，但不能建索引。

## 5. 注意事项对照表

| 错误做法 | 现象 | 正确做法 | 依据 |
| --- | --- | --- | --- |
| 不建扩展 | 类型不存在 | CREATE EXTENSION | 实测 |
| JSON 数组存向量 | 无算子 | vector 字面量 | 实测 |
| 忘强转 | 推断失败 | ::vector | 实测 |
| 维度混用 | 报错 | 固定 n | 第 37 章 |
| 无索引大表 | 慢 | 第 39/40 章 | 实测 |
| 只存向量 | 无法展示 | 原文同存 | 第 44 章 |
| 猜距离阈值 | 效果差 | 评测 | 第 45 章 |
