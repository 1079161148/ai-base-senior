# 44 RAG最小闭环 · 完整版

## 0. 怎么用

跑 8/8。RAG 就是把文档切块存向量、检索 Top-K 块、拼进提示词；pgvector 承担中间的检索环节。

## 1. 概念

本章聚焦「RAG 最小闭环」，是 M06 向量数据库体系中的一环，建立在前面关系型基础之上。

## 2. 机制

```text
→ 切块 chunk
→ <=>
→ LIMIT k
```

## 3. API 逐个拆解

| API | 作用 | 注意 |
| --- | --- | --- |
| `切块 chunk` | 文档分段 | 见验收 |
| `<=>` | 块检索 | 见验收 |
| `LIMIT k` | 取上下文 | 见验收 |
| `拼 context` | 送入大模型 | 见验收 |

## 4. 边界条件

- 向量维度必须与模型一致，算子要求维度相同。
- 近似索引以少量召回换取速度，需用评测校准。
- 教学用可复现向量验证机制，生产须换真实 embedding 模型。

## 5. 注意事项对照表

| 错误做法 | 现象 | 正确做法 | 依据 |
| --- | --- | --- | --- |
| 块太大 | 噪声多 | 合理分块 | 实测 |
| 块太小 | 语义断裂 | 保留重叠 | 实测 |
| 不按 doc 过滤 | 跨文档串味 | 加 doc_id 条件 | 实测 |
| 无索引 | 量大变慢 | 建 HNSW | 实测 |

## 6. 最佳实践

先测正确性再测性能；每次调参都用固定评测集对比，避免凭感觉。
