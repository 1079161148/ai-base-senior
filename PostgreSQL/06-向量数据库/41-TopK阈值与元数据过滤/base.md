# 41 TopK阈值与元数据过滤 · 完整版

## 0. 怎么用

跑 7/7。真实检索是 ORDER BY 距离 LIMIT k 加 WHERE 元数据条件，必要时再用距离阈值过滤低质结果。

## 1. 概念

本章聚焦「Top-K、阈值与元数据过滤」，是 M06 向量数据库体系中的一环，建立在前面关系型基础之上。

## 2. 机制

```text
→ LIMIT k
→ WHERE 距离 < 阈值
→ WHERE 元数据列
```

## 3. API 逐个拆解

| API | 作用 | 注意 |
| --- | --- | --- |
| `LIMIT k` | Top-K | 见验收 |
| `WHERE 距离 < 阈值` | 质量控制 | 见验收 |
| `WHERE 元数据列` | 结构化过滤 | 见验收 |
| `1/(1+距离)` | 相似度分数 | 见验收 |

## 4. 边界条件

- 向量维度必须与模型一致，算子要求维度相同。
- 近似索引以少量召回换取速度，需用评测校准。
- 教学用可复现向量验证机制，生产须换真实 embedding 模型。

## 5. 注意事项对照表

| 错误做法 | 现象 | 正确做法 | 依据 |
| --- | --- | --- | --- |
| 无 LIMIT | 全表排序 | 始终限制 k | 实测 |
| 阈值拍脑袋 | 过滤过度或不足 | 用评测校准 | 实测 |
| 先过滤再排序搞反 | 结果错 | WHERE 在前 ORDER 在后 | 实测 |
| 元数据不建索引 | 过滤慢 | 补 B-tree | 实测 |

## 6. 最佳实践

先测正确性再测性能；每次调参都用固定评测集对比，避免凭感觉。
