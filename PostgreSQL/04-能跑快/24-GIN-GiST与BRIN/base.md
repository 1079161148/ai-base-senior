# 24 GIN、GiST 与 BRIN · 完整版

## 0. 怎么用

跑 9/9，再看第 4 节理解索引方法与数据结构的对应。

## 1. 概念

不同数据形态需要不同索引结构。多值用 GIN，几何/范围用 GiST，物理有序大表用 BRIN。

## 2. 机制

```text
JSONB/数组 → GIN（倒排）→ @> 包含
文本        → tsvector + GIN → @@ 匹配
范围/几何   → GiST → 重叠/包含
时间序列    → BRIN → 每块存 min/max
```

## 3. API 逐个拆解

| API | 作用 | 注意 |
| --- | --- | --- |
| `USING gin` | 建 GIN | 写入较慢 |
| `USING gist` | 建 GiST | 范围/几何 |
| `USING brin` | 建 BRIN | 数据须物理有序 |
| `to_tsvector` | 生成文档向量 | 需指定分词配置 |
| `plainto_tsquery` | 生成查询 | 自动 AND |
| `ts_rank` | 相关性 | 用于排序 |

## 4. 边界条件

- BRIN 的效果取决于物理顺序，乱序表上几乎无效。
- GIN 写入代价高，适合读多写少。
- 中文全文检索默认分词效果有限，需要额外配置字典。
