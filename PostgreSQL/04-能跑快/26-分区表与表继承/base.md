# 26 分区表与表继承 · 完整版

## 0. 怎么用

跑 10/10，再看第 4 节理解分区和继承的差别。

## 1. 概念

分区是「逻辑一张表、物理多张表」，用来管理超大表和按时间淘汰数据。

## 2. 机制

```text
INSERT → 按分区键路由到子表
SELECT  → 带分区键时剪枝，只扫相关子表
DETACH  → 秒级归档旧数据
```

## 3. API 逐个拆解

| API | 作用 | 注意 |
| --- | --- | --- |
| `PARTITION BY RANGE/LIST/HASH` | 分区策略 | 建表时指定 |
| `FOR VALUES FROM ... TO` | 范围 | 左闭右开 |
| `DEFAULT` | 兜底 | 防止越界报错 |
| `DETACH/ATTACH` | 装卸 | 可秒级归档 |
| `pg_inherits` | 元数据 | 查父子关系 |

## 4. 边界条件

- 分区键必须包含在唯一约束里，否则无法建全局唯一。
- `DETACH` 后子表变成普通表，父表不再包含其数据。
- 表继承不会自动传播索引和约束。

## 5. 注意事项对照表

| 错误写法 / 操作 | 现象 | 正确写法 | 依据 |
| --- | --- | --- | --- |
| 查询不带分区键 | 全分区扫 | 带键 | 实测 |
| 分区键套函数 | 剪枝失效 | 直接比较 | 实测 |
| 无 DEFAULT 分区 | 越界报错 | 建兜底 | 实测 |
| 继承当分区 | 无索引传播 | 声明式分区 | 实测 |
| 分区键不进主键 | 主键建不了 | 包含分区键 | 实测 |
| 忘 ANALYZE | 计划差 | 建后执行 | 原仓库 06 |
| 分区过细 | 元数据膨胀 | 合理粒度 | 实测 |
| 分区过粗 | 剪枝无效 | 按查询模式 | 实测 |
| DETACH 后忘处理子表 | 数据孤立 | 归档流程 | 实测 |
| 默认分区装太多数据 | 性能差 | 监控 | 实测 |
| 分区索引命名冲突 | 建失败 | 自动命名 | 实测 |
| 跨分区 UPDATE 分区键 | 行迁移 | 注意代价 | 实测 |
| 不查 pg_inherits | 结构不清 | 查元数据 | 实测 |
| 用继承做时间分区 | 功能弱 | 声明式分区 | 实测 |
| 跳过验收 | 剪枝未验证 | 10/10 再走 | 实测 |
| 不测越界插入 | 上线报错 | 补 DEFAULT | 实测 |
| 分区表无统计 | 计划差 | ANALYZE 父表 | 实测 |
| 把 DETACH 当删除 | 数据还在 | 分清语义 | 实测 |
