# 46 电商语义搜索工程化 · 完整版

## 0. 怎么用

跑 13/13。这是全教程收官章，一个脚本综合验证 M00–M06 的核心能力。

## 1. 概念

工程化不是堆技术，而是按场景把合适的能力拼起来：电商库提供结构化数据，向量提供语义理解，索引提供性能，权限与事务提供正确性。

## 2. 机制

```text
电商库(关系型) → 商品向量化 → 语义 Top-K ─┐
                                        ├→ RRF 融合 → 排序展示
关键词检索 ──────────────────────────────┘
↑ HNSW/B-tree 索引加速，视图汇总，权限隔离，事务兜底
```

## 3. 端到端拆解

| 环节 | API / 手段 | 对应模块 |
| --- | --- | --- |
| 建模 | `setup_shop` 四表 | M01 |
| 向量化 | `fake_embedding` + model 列 | M06 |
| 语义检索 | `<=>` + LIMIT + 类目过滤 | M06 |
| 混合召回 | RRF `1.0/(60+rank)` | M06 |
| 索引 | HNSW + B-tree + ANALYZE | M04 |
| 汇总 | 物化视图 | M05 |
| 权限 | 只读角色 GRANT | M05 |
| 一致性 | BEGIN/ROLLBACK | M03 |
| 评测 | Top-K 子集校验 | M06 |

## 4. 边界条件

- 视图里的查询向量是建视图时的字面量，生产应改用函数参数或应用层拼接。
- RRF 必须用浮点除法，整数除会得到 0。
- 教学向量可复现但不具备真实语义，生产须换 embedding 模型。

## 5. 注意事项对照表

| 错误做法 | 现象 | 正确做法 | 依据 |
| --- | --- | --- | --- |
| RRF 整数除法 | 分数恒 0 | 1.0 | 第 42 章 |
| 不记模型版本 | 不可复现 | model 列 | 第 43 章 |
| 不过滤元数据 | 跨类噪声 | WHERE 类目 | 第 41 章 |
| 灌数前建索引 | 质量差 | 后建 | 第 39 章 |
| 无评测 | 效果未知 | 评测集 | 第 45 章 |
| 无权限隔离 | 安全风险 | 只读角色 | 第 30 章 |
| 无事务 | 不一致 | BEGIN/ROLLBACK | 第 16 章 |
| 硬编码密钥 | 安全风险 | 环境变量 | 安全底线 |
| 大表无 ANALYZE | 计划差 | 定期 ANALYZE | 第 25 章 |
| 跳过验收 | 集成错 | 13/13 再走 | 实测 |

## 6. 最佳实践

按"正确性 → 可复现 → 性能 → 安全"的顺序落地；每一步都有可执行的验收断言，而不是只写文档。
