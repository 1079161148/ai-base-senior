# 16 事务与 ACID · 完整版

## 0. 怎么用

跑 11/11，再看第 4 节理解隔离性是怎么测出来的。

## 1. 概念

事务把多步操作打包，失败时回到起点。

## 2. 机制

```text
BEGIN → 语句1 → SAVEPOINT → 语句2 → 失败 → ROLLBACK TO → COMMIT
```

## 3. API 逐个拆解

| API | 作用 | 注意 |
| --- | --- | --- |
| `BEGIN` | 开始 | 可带隔离级别 |
| `COMMIT` | 永久生效 | 不可撤销 |
| `ROLLBACK` | 全撤 | 回到 BEGIN 前 |
| `SAVEPOINT` | 内部点 | 可嵌套 |
| `pg_backend_pid()` | 连接标识 | 多连接排查用 |

## 4. 边界条件

- Checker 用 autocommit，所以事务演示必须另开连接。
- 未提交的修改对其他连接不可见（READ COMMITTED）。
- DDL 在 PostgreSQL 里也可以回滚。

## 5. 注意事项对照表

| 错误写法 / 操作 | 现象 | 正确写法 | 依据 |
| --- | --- | --- | --- |
| autocommit 里回滚 | 无效 | 普通连接 | 实测 |
| 转账只做一半 | 总额错 | 同一事务 | 通用实践 |
| SAVEPOINT 重名 | 覆盖旧点 | 不同名 | 实测 |
| 事务里建库 | 不允许 | 另开连接 | 实测 |
| COMMIT 后回滚 | 无效 | 提前决定 | 实测 |
| 长事务不提交 | 膨胀+锁 | 缩短事务 | 通用实践 |
| 连接断开未提交 | 自动回滚 | 显式 COMMIT | 实测 |
| 不测隔离性 | 并发问题后现 | 双连接验证 | 实测 |
| 把单语句当非事务 | 概念错 | 自动事务 | 实测 |
| CHECK 违反后继续用事务 | 状态异常 | 先回滚 | 实测 |
| 事务里做网络调用 | 拉长事务 | 移出事务 | 实测 |
| 不设默认隔离级别 | 靠默认 | 显式了解 | 通用实践 |
| 用 TRUNCATE 回滚测试 | PG 支持 | 可用 | 通用实践 |
| 不查 pg_backend_pid | 多连接难排查 | 记录 pid | 实测 |
| 事务嵌套误用 | SAVEPOINT 混乱 | 明确层级 | 实测 |
| 不检查约束违反 | 脏数据 | 捕获异常 | 实测 |
| 跳过验收 | 原子性未验证 | 11/11 再走 | 实测 |
| 把事务当性能优化 | 语义工具 | 正确理解 | 实测 |

## 6. 最佳实践
